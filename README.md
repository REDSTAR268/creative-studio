# Creative Studio Website 🚀

A modern, responsive Creative Studio website built with **React, JavaScript, Tailwind CSS, and Vite**.

Creative Studio is designed to showcase creative services, present completed projects, introduce the team, and allow visitors to get in touch through a contact form.

## 🌟 Features

- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Modern Hero Section:** An attractive landing page with engaging visuals.
- **About Section:** Introduces the creative studio.
- **Services Section:** Showcases the services offered.
- **Portfolio Section:** Displays creative projects and work samples.
- **Testimonials Section:** Presents client feedback.
- **Contact Section:** Provides a way for visitors to send inquiries.
- **Dark and Light Mode:** Allows visitors to switch between themes.
- **Reusable Components:** Built with organized and reusable React components.
- **Modern Visual Effects:** Includes attractive imagery, animations, and styling.

## 🛠️ Technologies Used

- JavaScript (ES6+)
- Tailwind CSS v4
- CSS

- HTML5

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/REDSTAR268/creative-studio.git
```

### 2. Navigate into the project folder

```bash
cd creative-studio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the local website

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
